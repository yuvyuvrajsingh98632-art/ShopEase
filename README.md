# ShopEase – E-commerce Website

## About the Project
ShopEase is a simple e-commerce web application where users can browse products, view product details, add items to a shopping cart, and place orders. The project demonstrates the basic functionality of an online shopping website.

## Features
- Display products with names, prices, and images
- Add products to the shopping cart
- View and manage cart items
- Calculate the total price
- Place orders
- Order confirmation page
- Responsive user interface

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Storage:** Browser Local Storage for cart data
- **API:** Express REST API for product data

## Products
The application includes sample products such as:
- Headphones
- Smartwatch
- Backpack
- Running Shoes
